# Cars Dealership - Full Stack Development Capstone Project

**Repository Name:** fullstack-cars-dealership

**Project Name:** Cars Dealership - Full Stack Development Capstone Project

## Project Description
A full-stack web application for a car dealership retailer that allows users to view dealership locations, explore dealer details, register and log in, and submit reviews.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django, Flask, Node.js
- Database: MongoDB, SQLite
- Deployment: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions

## Project Objectives
- Display dealership information.
- Allow users to register and log in.
- Enable users to submit and view dealership reviews.
- Analyze review sentiment.
- Deploy the application using cloud technologies.
